听雨剑谱

看破一息，胜过十剑。

沈砚与裴寂在雨夜交手。留意对方的起手动作与危险提示，利用收招破绽出剑。

W A S D 进退
按相机朝向行走，角色朝移动方向转身。点击下方「奔跑」切换行走与奔跑；按住 Shift 可临时冲刺。手机左摇杆移动，奔跑键始终可见，推满摇杆也可临时冲刺。
鼠标 / Tab 镜头
按住鼠标左键或右键拖动画面，可环绕观察；滚轮缩放远近，Tab 切换锁敌。手机在右侧空白处单指滑动转镜头，双指缩放。
[ ] / PgUp PgDn 键盘镜头
按住 [ 或 ] 水平转向，PageUp / PageDown 调整俯仰；− 拉远，+ 或 = 拉近。
J 普攻三段
近身按住「出剑」或连续按 J，可衔接三段剑招；命中后仍有恢复间隙，远处挥剑不会造成近战伤害。
R 跳跃 / 跳击
R 或「跳跃」跃起；空中按 J 为跳击，每跳一次空中出剑。展开「跳击 / 蹲击」，点「踏空斩」会完成起跳到空击的衔接。
C 蹲身 / 蹲击
按住 C 或「按住蹲」低身慢步，松开站起；此时按 J 为蹲击。展开招式，点「潜身扫」会短蹲后低扫。组合招式与普通攻击共用恢复间隙。
K 格挡
点按进入短暂格挡；在攻击将至的瞬间按下，尝试完美弹反。
L 闪避
沿移动方向翻滚闪避；无方向输入时后撤。按钮显示实际恢复时间，恢复完成后再用。
SPACE 剑气
消耗 45 剑意释放前进的月牙剑气，剑意会逐渐恢复。
Q 回风断雨
起势、旋身出剑、收势，攻击身边的对手；使用后需 8 秒恢复。
E 踏影惊鸿
短暂起势后向对手推进刺击，再收剑站稳；使用后需 5 秒恢复。
ESC 暂歇
暂停或继续。切换页面会自动暂停，触屏可点按下方招式。

画面可通过上方「画质」在自动、清晰与流畅之间切换；自动会随运行情况调整。
手机左侧摇杆移动，杆上方可直接切换奔跑、跳跃和按住蹲身；右侧常用招式保留，「跳击 / 蹲击」展开后可直接释放组合招式。试剑为可反复重试的单人陪练：平时不追打，靠得太近会后退；你出招或命中后，对手会反击 3 秒。再次出招或命中会延长反击，生命不自动恢复，仍可能受伤或失败。剧情实战不受陪练规则影响；观战由程序操作，含低血量恢复辅助，用于展示完整流程；难度仍需真人试玩。首次加载完成后方可开始。
